# DevOps_Internship_Day-1_Worklog

# Linux Environment Setup & Basics
# Overview

In this task, I set up a Linux environment and practiced basic Linux commands to understand file system navigation, file management, permissions, and system monitoring, which are essential for DevOps roles.

# Tools Used

Ubuntu Linux.    
Terminal / Shell.    

# What I Did

Installed and accessed a Linux environment.    
Navigated directories using pwd, ls, and cd.     
Created and removed files and directories using mkdir, touch, rm and rmdir/ rm -r.    
Viewed and edited files using cat, less and vim.    
Checked and modified file permissions using ls -l, chmod and chown.    
Monitored system resources using df -h, free -m, top and htop.
